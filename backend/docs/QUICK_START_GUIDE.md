# TruFit Auto Center - Quick Start Guide

## For Administrators

### Initial Setup
1. **Login**: Use your admin credentials at the login page
2. **Set Up Roles**: Go to Settings > Roles and Permissions
   - Default roles are pre-configured (Admin, Supervisor, Service Advisor, Technician)
   - Create custom roles as needed
3. **Add Employees**: Go to Employee Management > Onboarding
   - Generate registration keys for new employees
   - Share the key with the employee for self-registration

### Daily Operations
- **Dashboard**: Monitor key metrics at a glance
- **Reports**: Check Sales, Inventory, and Financial reports weekly
- **Audit Logs**: Review system activity periodically

---

## For Service Advisors

### Creating an Estimate
1. Go to **Sales > Estimates**
2. Click **+ New Estimate**
3. Select or create a customer
4. Add vehicle information
5. Add line items (services and parts)
6. Save and submit for approval

### Managing Appointments
1. Go to **Appointments**
2. Click **+ New Appointment**
3. Select customer, date/time, and service type
4. Assign a technician
5. Save the appointment

### Converting Estimate to Sales Order
1. Open an approved estimate
2. Click **Convert to Sales Order**
3. Review the order details
4. Submit for processing

---

## For Technicians

### Viewing Job Orders
1. Go to **Services > Job Orders**
2. View assigned jobs
3. Click on a job to see details

### Updating Job Status
1. Open a job order
2. Click **Start Work** when beginning
3. Update status as you progress
4. Click **Complete** when done

### Time Tracking
- Use the timer feature to track work hours
- Pause timer during breaks
- Resume when continuing work

---

## For Sales Staff

### Processing Sales
1. Go to **Sales > Sales Orders**
2. Review pending orders
3. Approve orders for processing
4. Track order status

### Managing Billing
1. Go to **Sales > Billing**
2. View outstanding invoices
3. Record payments
4. Generate receipts

---

## For Inventory Staff

### Checking Stock
1. Go to **Products > Inventory**
2. View current stock levels
3. Check low stock alerts

### Receiving Goods
1. Go to **Purchasing > Goods Receipts**
2. Select the purchase order
3. Confirm received quantities
4. Save the receipt
